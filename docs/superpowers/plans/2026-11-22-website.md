5. Implement hierarchical docs layout with individual routes, TOC anchors, previous/next links and copyable language-selected code. Adapt all 34 Chinese public articles except console/model-experience; preserve article provenance and clearly identify source-specific announcements.
6. Test filtering, query persistence, detail data consistency, deep routes, selected plans, code-copy selection and doc route coverage. Build/lint/tests plus local browser desktop/mobile checks.
